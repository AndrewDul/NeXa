# docs/capabilities/

Home for the **Capability System** documentation once it exists.

The Capability System will eventually answer: *"What can NeXa actually do, given
this hardware, these permissions, and this runtime state?"* Capabilities are
**derived** from Device Awareness + policy/consent + runtime state — not
hard-coded per device.

Planned milestone: **M4 — Device Awareness + Capability Registry**
(see `docs/ROADMAP.md`).

Empty at M0 — nothing is designed or implemented yet.
