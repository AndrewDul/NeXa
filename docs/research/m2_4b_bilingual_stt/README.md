# M2.4B.4 — Bilingual Voice Input Research & Benchmark

Raw evidence for `docs/reports/R0024_m2_4b_4_bilingual_voice_input_research_benchmark_20260908.md`.

**Research only.** Nothing here is imported by `src/nexa` or `apps/`. It does
not change the production `VoiceRuntime` explicit-language behaviour
(ADR-0003 D5) — this stage only gathers the evidence needed to decide
whether D5 should be superseded.

## Contents

| path | what |
|---|---|
| `corpus.py` | the fixed 50-utterance ground-truth corpus (15 PL, 15 EN, 10 short/ambiguous, 10 mixed/code-switch). Importable; JSON via `python corpus.py`. |
| `capture_corpus.py` | the operator recorder — records each utterance once from the known-good `"respeaker"` mic (resolved by name via `nexa.voice.device.find_device_index`) as 16 kHz mono PCM16 WAV. No ALSA config, no device index by hand. Resume-safe. |
| `fixtures/corpus_manifest.json` | ground truth (always regenerated by the recorder; safe to commit). |
| `fixtures/audio/<uid>.wav` | the operator's recordings (created by `capture_corpus.py`). |
| `fixtures/corpus.jsonl` | per-recording metadata (filename, duration, level, timestamp) merged with ground truth. |
| `bench_*.py` / `bench_*_*.json` | the STT-strategy benchmark + raw results (added after the corpus exists). |

## Step 1 — operator records the corpus (once)

```
./.venv/bin/python docs/research/m2_4b_bilingual_stt/capture_corpus.py
```

For each numbered sentence: press **Enter**, say it once clearly, press
**Enter** again to stop. `r` re-records the take just made, `s` skips, `q`
quits. Re-running the command continues where it left off.

## Step 2 — benchmark (after recordings exist)

Baseline first: whisper.cpp `base/q8_0` explicit `-l pl` and explicit
`-l en` — the ADR-0003 D4/D5 reference numbers. Then the evidence-backed
automatic strategies (`-l auto` direct; `--detect-language` → explicit
decode; and, if research justifies it, one lightweight external
language-ID). Metrics per group (PL / EN / SHORT / MIXED), never a single
global score: language-ID correctness + confusion matrix, WER, semantic
error class (S0–S3), latency / RTF, CPU / RAM / temp / throttle.

## Environment (verified 2026-09-08)

- whisper.cpp **v1.9.3** (Aug 2026) — the current stable release; already
  what NeXa pins (`nexa.stt.config.WHISPER_CPP_TAG`). MIT, ggml-org,
  actively maintained.
- `whisper-cli` supports `-l auto` (detect-then-decode) and `-dl` /
  `--detect-language` (detect-and-exit); recent releases exposed
  `whisper_lang_id()` and candidate/probability language detection.
- Model on disk: `ggml-base-q8_0.bin` (~78 MB) at
  `~/.local/share/nexa/stt/models/`.
